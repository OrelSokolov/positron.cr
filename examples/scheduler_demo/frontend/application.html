Crystal-планировщик: блокирующий цикл против UI

Локальное время (JS): —
Хост-тик: ещё не было

«Хост-тик» обновляется событием demo.tick из Crystal каждые 250 мс. Нажмите «Заморозить» — тики и все кнопки встанут, хотя локальные часы продолжат идти (JS живёт в процессе WebKit). «Занять с yield» держит UI живым, отдавая управление каждые 50 мс. «В subprocess» — настоящий параллелизм: цикл считает отдельный процесс, хост вообще не занят.
