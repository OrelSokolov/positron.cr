Positron.async_work_n_threads(threads: n) запускает блок по разу на каждый Parallel-поток: диапазон 300M юнитов делится статически по индексу воркера, поэтому N воркеров считают её ~в N раз быстрее. Все воркеры делят один токен — пауза и стоп действуют на весь отряд сразу. Контрольная сумма (XOR хешей юнитов) не зависит от числа воркеров — сверьте её между запусками.
